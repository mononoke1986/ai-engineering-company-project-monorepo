# Skill: Crear una nueva página web
## Objetivo
Crear una página HTML nueva en la carpeta correcta (`/uis/website`).

## Inputs (Ingredientes)
- Nombre de la página.
- Título de la página.
- Texto que llevará la página.

## Criterios de aceptación (¿Cómo saber si salió bien?)
- [ ] El archivo se creó dentro de `/uis/website`.
- [ ] Tiene la estructura básica de HTML.
- [ ] El título coincide con lo que pidió el usuario.
